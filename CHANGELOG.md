# Changelog

All notable changes to the Stave project are documented here.
The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [0.1.0] — initial release

### Added
- KawPoW proof-of-work chain: 144-second blocks, 600 blocks per day.
- Emission schedule: 31 STV per block at step 1, halving every 480,000 blocks, cap 29,760,000 STV. Zero premine.
- Windows wallet build v0.1.0 with published SHA-256.
- Project website: landing page, downloads with checksums, static block explorer.
- Documentation: whitepaper, mining guide, wallet guide, transparency page.
