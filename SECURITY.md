# Security Policy

## Supported versions

| Version | Supported |
|---|---|
| 0.1.x | yes |

## Reporting a vulnerability

Open a GitHub security advisory (the *Report a vulnerability* button on the repository's Security tab) rather than a public issue.

Include what you found, how to reproduce it, and what you think the impact is. You will get an acknowledgment, a status update as the fix is developed, and a public credit if you want one once the fix ships.

## Scope

- Consensus and validation logic (anything that would split the chain or accept invalid blocks) is the highest priority.
- Wallet: anything that risks funds or key material.
- Website and explorer: content injection or anything that misrepresents chain data.

## What this is not

Stave is experimental software published for study. Reports are welcome and taken seriously, but nothing here is an offer of a bounty, and no software should be trusted with amounts you cannot afford to lose.
