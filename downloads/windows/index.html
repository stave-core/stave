Verify before running

  1. Download the archive from the button above or from the GitHub releases page.
  2. Compute the checksum in PowerShell:
    Get-FileHash Stave-0.1-win-x64.zip -Algorithm SHA256
  3. Compare the output against the SHA-256 printed on this page. It must match exactly.
  4. Unpack and run the wallet. First start will sync the chain — the block schedule you see on the way is the one documented on the site.
A matching checksum proves the archive is the one published here — it is not a review of the software. The source is open under MIT; building from source is always an option. Treat experimental software accordingly and keep large amounts off machines you do not control.
