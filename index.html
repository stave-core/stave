STAVE

The oldest join in the shop: the chain holds because the pieces match.

A barrel is not held together by glue. It holds because the hoop presses every stave against its neighbour at once — remove one stave and the whole thing falls apart, keep them all and the vessel carries wine for decades. Stave is a proof-of-work coin built the same way: every block is one stave, the consensus rule is the hoop, and the chain holds because each block is pressed against every other by the same arithmetic.

The vessel

The cooper works to one measure: every stave is cut to the same curve, or the hoop will never seat. The chain works the same way — the whole supply is a closed formula, the test for entry is identical for the first miner and the last, and nothing about the plan is renegotiated afterwards. A block that does not match the curve is not pressed into the barrel; it is set aside.

Cast, not promised

No premine, no ICO, no founder allocation. The first STV is minted under exactly the same rule as the last one. Nobody gets a head start.

GPU-minable

KawPoW is the proof-of-work algorithm behind the block: memory-heavy work suited to ordinary graphics cards, re-aimed after every block so the cadence holds while hardware comes and goes.

Verifiable, not promised

Open source under MIT. Every number below is a rule of the chain, not a road-map wish — reproduce them by hand from the source.

The tightening

A cooper drives the hoops down as the staves settle, and the vessel grows tighter with age. The emission follows the same figure: each set of 480,000 blocks halves the reward, and the sum of the whole series lands on exactly 29,760,000 STV — the cap is a closed formula, 2 × 31 × 480,000, not a decision.
