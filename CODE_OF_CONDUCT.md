# Code of Conduct

## Our standard

Be precise, be honest, be civil. Criticism of code, numbers and documentation is the engine of this project and is always welcome. Personal attacks, harassment, and spam are not.

## Scope

This applies to the repository (issues, pull requests, discussions) and to any project space.

## Enforcement

Maintainers may remove comments, closes issues, and block accounts that violate this standard. Repeated or severe violations lead to a permanent block. Reports go through a GitHub issue or a security advisory if sensitive.

## Attribution

This standard is deliberately short. It borrows its spirit from the Contributor Covenant, without importing its text.
