# Contributing to Stave

Thank you for looking at the source — that is the point of it.

## Ways to take part

- **Read and report.** Open an issue for anything that looks wrong: a bug, a documentation error, or a number on the site that disagrees with the code. The last category is treated as the most serious.
- **Build from source.** Reproducing the binaries from source is the strongest review there is; report any divergence.
- **Propose changes.** Pull requests are welcome. Keep them focused: one logical change per PR, with a short description of what and why.

## Ground rules

- The emission schedule, block time and cap are consensus rules. Changing them is a fork of the whole project, not a code edit — such PRs will be discussed as such.
- Documentation must never promise anything the code does not already do.
- Be precise and civil. Reviews of the work are welcome; reviews of people are not.
